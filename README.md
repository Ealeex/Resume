# Ethan Lee — Portfolio

An interactive, space-themed portfolio highlighting my experience in software development, IT systems, networking, technical support, and full-stack web development.

## Live site

[View the portfolio on GitHub Pages](https://ealeex.github.io/Resume/)

## Highlights

- Immersive Three.js scene with section-based camera movement
- Snap-scrolling portfolio panels
- Skills grouped by discipline with animated proficiency bars
- Expandable project details
- Deep-space and black-and-gold themes
- Focused Hiring Manager Mode
- Downloadable PDF résumé
- Responsive layout and keyboard navigation

## Run locally

This is a static site with no build step. Clone the repository and open `index.html` in a browser, or serve the directory with any static HTTP server.

```bash
git clone https://github.com/Ealeex/Resume.git
cd Resume
```
